# Пример базы знаний

Положите сюда .md-файлы с данными бизнес-партнёра (регламенты, FAQ, описание продуктов).
Каждый абзац, разделённый пустой строкой, считается отдельным чанком для поиска.

Компания обрабатывает заявки клиентов в течение 24 часов. Срочные заявки — в течение 4 часов.

Возврат средств возможен в течение 14 дней с момента покупки при наличии чека.
