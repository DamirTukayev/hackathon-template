Задача: оформить спеку для идеи: $ARGUMENTS

Действуй так:

1. Прочитай `specs/README.md` (процесс и правила), `specs/_template.md`, `specs/000-product.md` и `CLAUDE.md`. Посмотри существующие `specs/NNN-*.md`, чтобы взять следующий свободный номер и не дублировать фичи.
2. Если идея размытая — задай не более 3 коротких уточняющих вопросов (кому нужно, что увидит жюри, что точно НЕ делаем) и дождись ответа. Если понятна — не спрашивай.
3. Создай `specs/NNN-<slug>.md` строго по `_template.md`:
   - метаданные: `id` = номер в кавычках, `owner` — по зоне (спроси, если неочевидно), `status: draft`, `contract: yes`, если меняются события чата / API / типы;
   - AC — проверяемые, измеримые формулировки; обязательно один про `DEMO_MODE`;
   - контракт — сверься с `apps/api/app/ai/router.py` и `apps/web/src/features/chat/types.ts`, ничего не выдумывай;
   - «Задачи по зонам» — по ролям из `CONTRIBUTING.md` (раздел 1), каждая строка с `[ ]`;
   - «Вне скоупа» не пустой.
4. Спека должна влезать в один экран. Если больше — предложи разбить на две.
5. Добавь строку в таблицу «Фичи» в `specs/000-product.md`.
6. Запусти `python3 scripts/spec_lint.py` и исправь замечания.
7. Код не пиши. В конце кратко перечисли: что в спеке, какие допущения сделал, что нужно решить людям. Ветку/коммит/PR не создавай, пока не попросят (процесс — в `specs/README.md`).
