# Правила для ИИ-агентов в этом репозитории

Хакатон-проект: React 19/Vite/Tailwind v4/Base UI/TanStack/Jotai + FastAPI + LLM. Дедлайн жёсткий — простое решение лучше красивого.

## Команды
- `make -j2 dev` — API :8000 + Web (Vite, порт может отличаться), `DEMO_MODE=true make -j2 dev` — офлайн
- `make fmt` — автоформат, `make check` — то же, что CI. Запускай перед тем как сказать «готово».
- Pre-commit хук (`.githooks/`) сам форматирует застейдженное и блокирует `.env`/ключи. Не обходи его через `--no-verify`.

## Синхронизация с командой
- В начале работы (и перед созданием ветки, перед PR) делай `make sync` и коротко сообщи пользователю, что пришло в `main` (список коммитов), особенно если затронуты `requirements*.txt`, `package.json`, `.env.example`, контракт чата или правила.
- Если `make sync` подсказал `make install` — выполни его до запуска тестов/сборки.
- Не делай `git push --force` и не переписывай чужие коммиты; конфликт при rebase — покажи пользователю, не угадывай.

## Структура
- `apps/api/app/ai/` — вся ИИ-логика. Роуты в `api/routes/` тонкие.
- `apps/web/src/` — FSD: `app/ pages/ features/ shared/`. Новая фича = `features/<name>/{ui,model,api}/` + `index.ts`. Импорт из фичи только через её `index.ts`.
- Состояние: серверное — TanStack Query, клиентское — Jotai, формы — TanStack Form, UI-примитивы — Base UI (обёртки в `shared/ui/`).

## Жёсткие правила
- Контракт SSE-событий живёт в двух местах: `apps/api/app/ai/router.py` и `apps/web/src/features/chat/types.ts`. Меняй оба одновременно, новые поля делай опциональными.
- Любая новая AI-функция должна работать в `DEMO_MODE` (ответ в `data/demo_cache.json` или ветка в mock-провайдере) и иметь фолбэк при ошибке провайдера.
- Не коммить `.env` и ключи. Новые переменные — в `.env.example`.
- Не трогай чужую зону без причины (см. `CONTRIBUTING.md`, раздел 1) и не делай «заодно» массовых рефакторингов/переформатирования — это рождает конфликты.
- Без новых зависимостей, если задача решается стандартной библиотекой или уже установленным пакетом.
- Модели: по умолчанию `claude-sonnet-5-5`, задаётся через `ANTHROPIC_MODEL`, не хардкодь.
