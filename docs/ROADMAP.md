# Roadmap на 48 часов

Правило: **к часу 6 уже есть работающее демо end-to-end**, дальше только улучшаем его. Feature freeze — час 36.

| Часы | Фаза | Что делаем | Результат / критерий |
|---|---|---|---|
| 0–1 | Старт | Разбор кейса партнёра, одно предложение ценности, user story, 3-минутный сценарий демо. Роли: AI/backend, frontend, продукт+питч. Ключи API, `make install`. | Все запускают шаблон локально |
| 1–6 | **Core MVP** | Главный AI-сценарий end-to-end на реальных данных партнёра: промпт → ответ в UI со стримингом. Заполнить `knowledge/` и `demo_cache.json` (запись «золотых» ответов). Деплой hello-world. | Один сценарий работает от клика до ответа; задеплоен |
| 6–16 | Ширина | 2–3 дополнительных сценария, RAG по данным партнёра, tool-calls / структурированный вывод, история, обработка ошибок. | Все сценарии демо проходят |
| 16–24 | Интерфейс | Дизайн-полировка, пустые/загрузочные/ошибочные состояния, мобильная вёрстка, «вау-элемент» (визуализация, источники ответа, метрики экономии). Сон по очереди! | UI выглядит как продукт |
| 24–30 | Стабильность | Деплой на постоянный URL, прогон 20 тестовых запросов (eval), кэш частых ответов, логирование, проверка фолбэков (выдернуть ключ — демо живо). | Устойчиво к падению API |
| 30–36 | Вау и метрики | Добавить то, что отличает от других: измеримый эффект для партнёра, edge-кейсы. **Feature freeze в 36.** | Продукт «закрыт» по функционалу |
| 36–42 | Материалы | Запись демо-видео (2–3 мин, по сценарию, с `DEMO_MODE`-запасом), слайды (проблема → решение → демо → архитектура → эффект → дальше), README. Параллельно: баги. | Видео и презентация готовы |
| 42–46 | Репетиция | 2–3 прогона питча по таймеру, ответы на вопросы жюри, только критичные багфиксы. | Питч укладывается в время |
| 46–48 | Буфер | Сабмит **за 2 часа до дедлайна**, проверка ссылок, репо, видео с чистого устройства. | Отправлено |

## Распределение по ролям (3–4 человека)

- **AI/Backend:** `ai/`, промпты, RAG, eval, деплой API.
- **Frontend:** `features/`, UX, деплой web.
- **Продукт/питч:** кейс, данные, сценарий демо, слайды, видео с часа 24.
