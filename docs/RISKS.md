# Риски и страховки

| Риск | Страховка (в шаблоне уже есть ↗) |
|---|---|
| Упал/лимитит API провайдера | Цепочка `AI_PROVIDERS=anthropic,openai,mock` — автофолбэк ↗ `ai/router.py` |
| Модель «зависла» | `FIRST_TOKEN_TIMEOUT` (8 с) → переход к следующему провайдеру ↗ |
| Нет интернета/wifi на площадке | `DEMO_MODE=true` — всё на заготовленных ответах, UI не отличим от живого ↗ `providers/mock.py` |
| Длинный ответ, скучно ждать | Стриминг + индикатор печати + кнопка «Стоп» ↗ `features/chat` |
| Непредсказуемый ответ модели на сцене | Демо ведём по заранее проверенным запросам; «золотые» ответы в `demo_cache.json`; temperature ниже, строгий промпт |
| Кончились кредиты / ключ утёк | Ключи только в `.env` (в `.gitignore`), запасной ключ у второго члена команды, лимиты на ключ, локальная модель через Ollama как третья ступень |
| Галлюцинации | Ответ только по контексту из RAG, «не знаю» в промпте, показываем источники |
| Деплой ломается за час до конца | Деплой hello-world на часу 6 и 24, не в конце; локальный запуск + видео как план Б |
| Прод ≠ локально (CORS, SSE буферизуется nginx) | Заголовок `X-Accel-Buffering: no` есть; проверить стрим на проде заранее |
| Видео не успели | Запись с часа 36, не позже 42; запасной вариант — запись экрана `DEMO_MODE` |
| Scope creep | Feature freeze в час 36; идеи «на потом» — в слайд «Roadmap» |
| Конфликты в git | Разные папки у ролей, мелкие коммиты, merge в main каждые 2–3 часа |
